# DEE GRAPHICS Portfolio

A modern, cyberpunk-themed portfolio website for DEE GRAPHICS — Visual Design Studio.

## Project Structure

```
dee-graphics/
├── index.html      # Main HTML file
├── styles.css      # All CSS styles
├── script.js       # JavaScript functionality
├── img/            # Image assets
│   ├── me.jpg      # Profile image
│   ├── me1.jpg     # Hero profile image
│   └── IMG-*.jpg   # Portfolio work samples
└── README.md       # This file
```

## Features

- **Cyberpunk Design**: Neon cyan/green/red color scheme with dark theme
- **Responsive Layout**: Mobile-first design that works on all devices
- **Interactive Elements**:
  - Custom cursor animation
  - Smooth scroll animations
  - Portfolio filtering
  - Image carousel with auto-advance
  - Glitch text effects
- **Sections**:
  - Hero with profile card
  - Services (Flyer Designs, Brand Designs, Logo Design)
  - Portfolio showcase
  - Design carousel
  - Client reviews
  - Contact information

## Technologies Used

- HTML5
- CSS3 (Custom properties, animations, grid/flexbox)
- Vanilla JavaScript
- Google Fonts (Orbitron, Rajdhani, Space Mono)

## Getting Started

1. Clone or download the project
2. Open `index.html` in a modern web browser
3. The site is fully self-contained with no external dependencies

## Customization

- **Images**: Replace files in the `img/` folder to update portfolio work
- **Content**: Edit text directly in `index.html`
- **Styling**: Modify `styles.css` for design changes
- **Functionality**: Update `script.js` for interactive behavior

## Browser Support

Works best in modern browsers that support:
- CSS Grid and Flexbox
- CSS Custom Properties
- ES6+ JavaScript features
- CSS backdrop-filter
